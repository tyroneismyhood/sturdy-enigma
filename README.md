# Unzip

**Upload a full codebase to GitHub from your phone without losing its folder structure.** GitHub mobile can't upload a folder tree, so Unzip lets you upload one ZIP instead. Almost any AI can make the ZIP for you, including ChatGPT and Claude apps.

1. Tap **Use this template** → **Create a new repository**.
2. Upload one `.zip` file to the new repository.
3. Done. Unzip runs automatically. If it pauses, open **Actions → Unzip** and follow the GitHub sign-in.

Delete `.github/workflows/unzip.yml` when you're done, or leave it there. Upload another ZIP later and Unzip will replace the repository with the new version.
